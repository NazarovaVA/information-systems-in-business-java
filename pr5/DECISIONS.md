# Принципиальные решения

1. **Вынос бизнес-правил в константы.**
   Все числовые пороги (максимум часов, дневная норма, недельная норма) вынесены в `private static final` переменные в классе `TimesheetAnalyzer` (например, `MAX_HOURS = 15`). Это сделано для того, чтобы изменение требования (например, изменение максимального порога на защите) затрагивало только одну строчку кода, а не размножалось по всему проекту.

2. **Разделение вычислений и вывода.**
   Класс `TimesheetAnalyzer` содержит только методы для парсинга строки и математических вычислений. Он ничего не выводит в консоль и не зависит от `SelfCheck`. Это позволяет переиспользовать класс в других программах и легко его тестировать.
